# pyChess
Chess game written in python using tkinter.

![pyChess_board.png](resources/pyChess_board.png)

Aim functionality:
- Move pieces ✓
- reverse button
- Show possible moves ✓
- remove pieces from board ✓
- start new game
- give piece back if pawn reaches end
- move order white -> black

Optional functionalities that might come
- save & load game
- Track moves
- Checkmate
- play vs AI
